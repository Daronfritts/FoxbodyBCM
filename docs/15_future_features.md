## Web Server

Status: Planned

Purpose:
- Using a Joying Android
- Monitor and control the BCM from any device on the local network.
- Allow secure remote access (optional through Tailscale or VPN).

Planned Features:
- Live dashboard
- Vehicle status
- Sensor readings
- GPIO status
- Start/stop logs
- Diagnostics
- Trouble codes
- Event logs
- Configuration pages
- Software updates
- Backup/restore configuration
